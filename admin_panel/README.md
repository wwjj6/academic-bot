# 🖥 لوحة تحكم البوت — Admin Panel

واجهة ويب (Flask) لإدارة بوت المسابقات الأكاديمية من المتصفح، دون الحاجة لتعديل الملفات يدوياً.

## ✨ ماذا يمكنك أن تفعل؟

- ⚙️ **تعديل جميع إعدادات البوت** (التوكن، الاسم، المشرفون، حدود الأسئلة...) مع الاحتفاظ بالقيم الحالية كافتراضية
- 📚 **إدارة المقررات** — إضافة/تعديل/حذف
- 👨‍🏫 **إدارة المدرسين** — إضافة وربطهم بمقرراتهم
- 🧑‍⚖️ **إدارة لجنة المسابقات**
- 🎓 **إدارة الطلاب** — عرض وتغيير الأدوار والحذف
- 🏆 **إدارة المسابقات** — تغيير الحالة، عرض النتائج، الحذف
- 🎛 **تشغيل/إيقاف/إعادة تشغيل البوت** ومتابعة سجله مباشرة

## 🚀 التشغيل

### الطريقة الأولى (الأسهل)
انقر نقراً مزدوجاً على ملف:
```
admin_panel\run_panel.bat
```

### الطريقة الثانية (يدوياً)
من مجلد المشروع الرئيسي:
```bash
pip install -r requirements.txt
python admin_panel/app.py
```

ثم افتح المتصفح على:
```
http://127.0.0.1:5000
```

## 🔐 أول استخدام

1. عند أول فتح ستُطلب منك **إنشاء كلمة مرور** لحماية اللوحة
2. بعدها سجّل الدخول بكلمة المرور في كل مرة
3. ابدأ من صفحة «⚙️ إعدادات البوت» لإدخال التوكن والمشرفين

## 📂 الملفات

```
admin_panel/
├── app.py              # تطبيق Flask (كل المسارات والمنطق)
├── config_io.py        # قراءة/كتابة config.json بأمان
├── run_panel.bat       # مشغّل ويندوز
├── panel_auth.json     # (يُنشأ تلقائياً) كلمة المرور ومفتاح الجلسة — لا يُرفع
├── static/style.css    # التنسيق (RTL)
└── templates/          # صفحات HTML
```

## ⚠️ ملاحظات أمنية

- اللوحة تعمل على `127.0.0.1` فقط (جهازك المحلي) — غير متاحة على الشبكة لحماية التوكن
- `panel_auth.json` (كلمة المرور) و `config.json` (التوكن) محميان من الرفع إلى GitHub تلقائياً
- تعديلات الإعدادات الأساسية تتطلب «إعادة تشغيل البوت» من اللوحة لتُطبَّق
